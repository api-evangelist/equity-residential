# Equity Residential

> Equity Residential (NYSE: EQR) is an S&P 500 real estate investment trust that owns and
> operates apartment communities in dense urban and high-density suburban markets across the
> United States. It is a property owner and operator, not a software vendor.

## API surface

Equity Residential publishes **no public API**. As of 2026-09-06 there is no developer
portal, no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK in any public package
registry, no MCP server, and no A2A agent card on any host in the equityapartments.com or
eqr.com namespace. Its public technology surface is consumer-facing: a leasing website, a
resident portal, and a mobile app.

- Domain security posture (TLS, HSTS, DNSSEC, CAA, SPF, DMARC) — see
  `security/equity-residential-domain-security.yml`.

## Notes for agents

Equity Residential is a **consumer** of third-party property-management and leasing APIs, not
a producer. Apartment availability and pricing appear on partner listing platforms rather
than through a first-party programmable interface. There is no endpoint here for an agent to
call. Do not infer an API base URL from the corporate domain.
